For you convenience you may DOWNLOAD the Desktop Version

1. Click on the link labeled "DOWNLOAD" to start downloading the game.
2. Choose "Extract All..." or "Unzip..." from the context menu.
3. Select a destination folder where you want the extracted files to go and confirm by clicking "Extract".
4. Open the folder where you extracted all the files. Ensure that all game files remain together in this single folder.
5. Look for the executable file named Lambousa 3D Puzzle.exe.
6. Open the executable and you are ready to play the game.
